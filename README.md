# React Auth App (with JSON Server)

A simple authentication app built with **React + Vite**, featuring:
- Login/Register forms
- LocalStorage-based auth
- Protected routes
- REST API backend with JSON Server
- Clean component structure and styling

---

### 1. Clone the repo

```bash
git clone https://github.com/your-username/react-auth-app.git
cd articles-app

### 2. Install dependencies

npm install


### 3. Run JSON Server (port 5000)

npm install -g json-server
json-server --watch db.json --port 5000


### 4. Start the React app

npm run dev
